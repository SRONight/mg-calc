# MagicGarden Calculator

Magic Garden의 게임 데이터를 바탕으로 작물과 펫의 가치를 계산할 수 있는 개인용 웹 계산기입니다.

게임 내에서 확인하기 번거로운 복잡한 가치 계산식을 쉽게 확인할 수 있도록, 필요한 정보를 선택하면 계산 과정과 최종 가치를 한눈에 확인할 수 있도록 만드는 것을 목표로 합니다.

## Features

### Crops Calculator

작물의 종류와 적용된 변이 및 날씨 효과를 선택하여 최종 가치를 계산합니다.

* 작물 검색 및 선택
* 작물의 기본 가치 표시
* 크기 배율에 따른 가치 계산
* Gold / Rainbow 변이 적용
* 날씨 변이 선택 및 적용
* 변이와 크기 배율을 포함한 계산 과정 표시
* 최종 작물 가치 표시

### Pets Calculator

추후 펫의 가치를 계산할 수 있는 기능을 추가할 예정입니다.

## Data

게임 데이터는 [Magic Garden API](https://github.com/Ariedam64/Magic-Garden-API)를 사용합니다.

이 프로젝트는 Magic Garden의 공식 프로젝트가 아니며, 개인적인 편의를 위해 제작되었습니다.

API에서 필요한 데이터를 제공하지 않거나 API를 사용할 수 없는 경우, 게임 위키의 공개된 정보를 참고하여 필요한 데이터를 직접 관리할 수 있습니다.

## Purpose

이 프로젝트는 개인적인 게임 플레이를 돕기 위한 비상업적 프로젝트입니다.

Magic Garden의 게임 데이터를 보다 쉽게 확인하고 계산할 수 있는 개인용 도구를 만드는 것을 목적으로 합니다.
